What am I paying for if the code is MIT licensed?

A prepared, documented release and its complete case pack. The license permits commercial use, modification and redistribution. There is no DRM or claim of exclusive access to an underlying secret-scanning technique.

Is this a security certification or a real-provider test?

No. A passing result covers these synthetic exercises only. The supplied reference implements the lab protocol. Real providers need their own authority rules and response contracts.

Does this expose my code or credentials?

The supplied runner listens on loopback and does not upload data. All included credentials are synthetic. Your own adapter is your executable code; the runner does not sandbox it.

Why not just use free tools?

Free tools may be the right answer. Canarytokens provides tripwires; SecretBench provides secret-detection datasets. This kit packages a narrower verification regression workflow. Start with the sample to see whether that saves you work.

Bait Lab is a developer experiment from Usual. Public Bait remains the bot-baiting playground. No visitor tracking scripts, remote fonts, or external requests on this page.
