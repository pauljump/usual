# Recall

Find what was said, with the source attached.

Part of [Usual](https://github.com/pauljump/usual).

## Source

Shared runtime: `src/usual/recall_core/`. Product installation, usage, storage and limitations are defined in [`src/usual/catalog.json`](../../src/usual/catalog.json).

## Checks and deployment

Run `python3 -m pytest -q` at the repository root. The public website uses `deploy/web.json`; portable downloads use `scripts/build_release.py`.
