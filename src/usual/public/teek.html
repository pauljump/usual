04 / THE DEFAULTS

Useful boundaries, built in.

Human-led. Named profile replies, turn by turn. The conversation stops until you reply. No invented commitments.

Bounded. Two jams per room, four rounds each, six attempts per jam. No automatic retries.

Grounded. Product context and source snapshots are frozen into each jam. Simulated lenses, not actual people or endorsements.

Private. Password gate, server-side credentials, shared transcripts visible to everyone with access. No personal-account privacy claim.

Recorded. Speaker-by-speaker transcript, source references, and a summary only at the end. General jam needs no category. Decision approval boards and GitHub task export are not implemented yet.

Honest about portability. New rooms use a shared Python engine and UI. Link them from any site. Last Bump remains a separate Node implementation; it has not been migrated.

The hub itself makes no model calls. New rooms remain disabled until their provider credential is configured through the vault. Existing Proof and Last Bump credentials are not inherited.
