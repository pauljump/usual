A few honest details

What “local” means

Usual’s runtime parses, stores, and searches selected history on your computer. It doesn’t upload a corpus to this website. Your existing coding model processes the evidence it reads under its provider’s normal policies.

What’s actually verified

This is a local beta. Fixture checks and scripted clients are distinct from live agent behavior. Browser and device behavior varies. Each tool lists its specific status; installation alone is not behavior verification.

Choices still works

Existing Usual decision memory is now called Choices on the menu. The /usual and $usual skill entry points, local data, review, and autonomy modes remain. Claude Code guide · Codex guide.

A website, not a connection

This page contains public synthetic examples. It has no transcript upload or private corpus endpoint. The hosting layer and older public pages may measure visits; the local CLI has no analytics. Read the privacy details.
