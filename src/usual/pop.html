What à la carte means for Pop

Choose the installation that fits your setup:

  • The plain instruction rule works without decision memory or history import.
  • The optional managed installer records local installation state and receipts. No account or CLI telemetry.
  • You can inspect the whole rule and change the selected browser.
  • Managed disable/removal preserves unrelated instructions. For a manual installation, remove only the Pop block you added.

Pop is an instruction rule. It changes how your coding agent writes links to you. It does not run a service, intercept commands, or replace your client's permission controls.

One item is a good order.

Pop changes how an agent hands you links. Escape, a separate item, changes a website to help visitors leave in-app browsers. You can use Pop on its own, inspect its managed installation and verification details, or browse all six tools.
