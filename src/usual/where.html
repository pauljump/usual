Usual / 07 / Where

Where was I?

Every Claude Code and Codex session on your machine, on one board. What each one is waiting on, which repos have uncommitted work, and which sessions Claude Code is about to delete. Click a card and it resumes in the right folder.

Paste this to Claude Code or Codex
read https://tryusual.com/where/install and install it
Or just run it
curl -fsSLO https://tryusual.com/where.py && python3 where.py board

Made-up sessions. Try the demo board.

What you get

The boardwhere board

A local page with every recent session. Search it, filter to the ones waiting on you, and press Resume. A new terminal opens in the folder the session started in and runs claude --resume or codex resume.

Just ask/where

The install adds a skill. Ask "where was I on the webhook thing?" and your agent finds the session, tells you what is still open, and hands you the resume command.

A brief, not a replaywhere brief ID

A short handoff note: what you asked for, which files changed, where it stopped. Paste it into a fresh session instead of reloading a huge one.

Keep your historywhere keep

Claude Code deletes transcripts after 30 days unless you change a setting. This shows how many are about to go and, if you say yes, turns it off and can archive a copy.

What it touches

Reads onlyTranscripts in ~/.claude/projects and ~/.codex/sessions. It never edits them. A small cache goes in ~/.usual/where.
Stays on your machineThe board listens on 127.0.0.1 with a one-time token. No account, no network calls, no telemetry.
One filePython 3.9+, standard library. Read the source. To remove it, delete ~/.claude/skills/where.

"Waiting on you" is read from the last exchange of each session, so it can be wrong. The resume command and git state are exact.
