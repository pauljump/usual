# A minimal contributor example

Run `python3 examples/catalog/hello.py` and
`python3 scripts/validate_catalog.py --catalog examples/catalog/item.json`.

The example returns one observable result, writes no files, uses no network, and
requires no history. It is a starting point for a complete implementation and
honest manifest, not an extra release menu item. Source: https://github.com/pauljump/usual.
