# Release source provenance

The canonical combined product is https://github.com/pauljump/usual. This release does not migrate or retire another repository.

- **Choices:** existing Usual runtime, command semantics, portable skill, database and review ledger retained. The new name is a catalog label. Legacy Itchy/Whetstone history remains in its existing archive and migration documentation.
- **Vibecheck:** product/guide concepts reviewed from https://github.com/pauljump/vibes, including its profiler and field guides. The maintained finding implementation is new Usual code over the chosen Recall adapter core. Heuristic grades and population percentiles are not reused as findings. Existing guide URLs remain references pending any separately approved upstream routing work.
- **Recall:** MIT Transcript Mine local parsing/index design adapted into `src/usual/recall_core`; it shares Usual redaction and human metadata filtering. The original MIT notice is retained. No X synchronization, Paul-specific compilation command, watch mode or provider API is included. See [source hashes and update strategy](history-provenance.md).
- **Loops:** stable method/variable input/correction ideas from the existing Codex Loops specification and Vibecheck Loops field guide. `file-check-v1` is a new maintained Usual routine engine, with explicit read-only checks and private receipts. Historical automation proposals grant no execution authority.
- **Pop:** adapted Usual-owned independent link rule and public entry paths, with managed installation and explicit verification status. Prior uncommitted Pop page/instruction work was deliberately carried into the isolated baseline and reconciled here.
- **Escape:** MIT dependency pinned to upstream commit `8ded426d530638ea334bfd137345114973f3d602`, release 1.0.0, distributed as `1.0.0+usual.1`. One visible-copy bug is patched. The original file, distribution file, license, exact hashes and update policy are in `src/usual/vendor/escape_webview/source.json`. Only the distribution file is served/installed; upstream remains canonical.

The portable-memory experiments informed inspectable evidence and correction UX only. No remote connector, private tester service, account, corpus or research brief is part of this release. All newly generated public findings, examples and setup cards use named synthetic fixtures.
